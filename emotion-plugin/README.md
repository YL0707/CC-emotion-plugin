# 情绪插件（拟态体系）

一个本地跑的情绪状态页：把「身体 / 情绪 / 关系 / 记忆」拆成能算的数，算完摊在一页上给人看。

## 它算什么
- 身体：体力、困倦、饥饿、健康，会跟着钟点和作息自己走
- 情绪：七种激素各有半衰期，情绪分「心里」和「嘴上」两层
- 底色：五维性格 + 嘴硬，按星座从 50 基线加减
- 关系：亲近、信任、依赖、安心、默契
- 主动额度：今天还能找你几条、间隔多久
- 怕：只有看鬼片、打雷、一个人走夜路这类事才触发，过后慢慢退

## 装法
1. 装 Python 3.10+（只需要标准库，不用装别的）
2. 双击 `start.bat`，浏览器打开 http://127.0.0.1:8099
3. 首次打开是空白设定：点右下角齿轮，把名字、生日、身高填进去，保存
4. 配色、缩放也在齿轮里调，存在浏览器本地

## 说明
- `profile.json` 是它自己的设定，第一次保存后生成；`profile.example.json` 是字段样例
- `memories.md` 可选，写进去的内容会显示在页面的记忆星图上
- 所有数据都在本机，不联网
