# 情绪引擎 3.0

一个能自己长心眼的情绪小引擎：填一页资料，她就有心跳、有激素、有心情，
说话的语气、要不要主动找你，都跟着心情走。纯本地，不联网、不要账号。

![主界面](docs/img/01-main-desktop.png)

> 想看每个参数是什么意思、怎么调，见 **[使用手册](docs/MANUAL.md)**（带截图、参数表、强度建议）。

## 一、怎么跑

**最简单**：双击 `情绪引擎3.exe`。

- 第一次启动会自己打开浏览器到 `http://127.0.0.1:8188/`
- 填完那一页（名字、称呼、生日、性格、作息、经期、立绘），点「就这样，开始」
- 之后它就一直在后台跑，每分钟心跳一次；再双击只会把页面打开，不会起第二个
- **第一次启动会自动帮你设好开机自启和崩溃守护**，什么都不用配；
  不想要就在面板最下面点一下「已开 · 点这里关掉」
- 配置写在 exe 旁边的 `config.json`，状态在 `data/state.json`，每天自动备份到 `data/backup/`
- 8188 被别人占了会自动往后挪（8189、8190…），页面地址以自动打开的那个为准

源码跑法（装了 Python 的话）：

    python app.py              # 默认 8188
    python app.py 9000         # 换端口
    python app.py --no-browser # 不自动开浏览器
    python app.py --install    # 开机自启 + 崩溃守护（写 HKCU 的 Run 键 + 建一个计划任务，都不要管理员）
    python app.py --uninstall  # 两样一起撤掉

（exe 也一样：`情绪引擎3.exe --install`。）

开了守护之后，它每 5 分钟自查一次；万一被关掉或崩了，五分钟内自己回来，不弹窗、不抢焦点。

## 二、它有什么

- **七个激素**：肾上腺素、多巴胺、血清素、皮质醇、催产素、内啡肽、褪黑素；
  外加随机体：体力、困倦、饥饿、健康；以及愉悦度 / 唤醒度两个坐标
- **心情是算出来的**：激素 + 性格（六个滑杆 + 星座底色）+ 关系 + 身体 → 一个词
- **词有层次**：从「特别开心 / 很开心 / 开心」到「有点吃醋 / 炸毛 / 冷淡 / 心软 / 想黏你」，
  还有一层「嘴上说的」跟「心里想的」不一样（嘴硬）
- **软饱和**：越接近 100 涨得越慢，不会一句话顶格；同类事件短时间内反复来会递减
- **昼夜节律**：按你填的作息，到点会困、早上会醒
- **生理周期**：填了起始日就按 28 天推雌激素、孕激素，情绪跟着起伏
- **主动开口**：心情好一天能主动找你五条，心情差就躲着；夜里不找你
- **记仇也记好**：最近 40 件事都带起因（因为哪句话、哪种事）
- **默认形象是一条大肥鱼**：不传立绘也能看见她；想换成自己的，点立绘区那句话上传一张，
  透明底 PNG 最好（或者直接把图片覆盖 `assets/default.png`）

## 三、怎么接别人的程序

这是它最有用的一面：把它当「情绪中间件」，你的聊天程序只需要三件事。

**1. 用户说了一句话——告诉它**

    POST http://127.0.0.1:8188/api/event
    {"kind": "praise", "intensity": 1.0, "why": "他说好看"}

`kind` 一共 17 种：`praise 夸她 / miss 说想她 / tease 逗她 / ignore 不理她 /
cold 冷淡 / worry 关心她 / comfort 哄她 / goodnight 说晚安 / scare 吓她 /
proud 为她骄傲 / hug 抱抱 / late_night 熬夜 / eat 吃饭 / rest 休息 /
horror 看恐怖片 / thunder 打雷 / night_walk 走夜路`

懒得自己判断？直接把原话丢给判定：

    POST http://127.0.0.1:8188/api/classify
    {"text": "你今天真好看", "apply": true}

回 `{"hit": {"kind":"praise","score":1.0,"why":"好看","cn":"夸她"}}`；
`apply: true` 的话它顺手就把情绪推进去了。
（Python 里也可以直接 `from classify import guess`）

**2. 说话之前——问它现在什么心情**

    GET http://127.0.0.1:8188/api/state

常用的字段：`emotion.label`（嘴上说的）、`emotion.inner`（心里想的）、
`emotion.valence`、`emotion.arousal`、`proactive.left`（今天还能主动说几句）、
`cycle.stage`、`clock`。把它拼进你的 system prompt 就行，
比如「她现在心情是『有点吃醋』，说话别太欢。」

**3. 她主动说了话——记一笔**

    POST http://127.0.0.1:8188/api/mark-proactive

## 四、备份、搬家

- 「导出数据」下一个 json（配置 + 状态全在里面）
- 换电脑：把整个文件夹拷过去，或者新机器上跑起来后「导入数据」
- 自动备份在 `data/backup/`，保留最近 7 天

## 五、排错

- 打不开？点「自检」，它会把数据目录、网页文件、心跳、资料一项项列出来
- 还不行就看 exe 旁边的 `error.log`
- 端口被占：`情绪引擎3.exe 8288` 换一个
- 想让立绘动起来：把 Live2D 模型目录放进 `assets/`，在 `config.json` 的
  `profile.live2d` 写模型名（这一版只留了位，渲染要自己接）

## 六、目录

    app.py        HTTP 服务 + 心跳 + 网页
    engine.py     情绪引擎（激素、心情、曲线、主动开口）
    config.py     配置的读写与默认值
    classify.py   一句话 → 事件
    web/          网页面板
    assets/       立绘等图片
    data/         状态 + 每日备份
