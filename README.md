# CC-emotion-plugin · 情绪插件（拟态体系 v0.2）

一个**纯本地**跑的情绪状态面板：把「身体 / 情绪 / 关系 / 记忆」拆成能算的数字，算完摊在一页上看。
Python 标准库 + 一个网页，不用装依赖，不联网，数据都在本机。

![面板](docs/screenshot.png)

## 它算些什么

| 层 | 内容 |
| --- | --- |
| 身体 | 体力、困倦、饥饿、健康，跟钟点和作息自己走 |
| 情绪 | 七种激素各有半衰期（肾上腺素 8 分钟～褪黑素 5 小时），情绪分「心里」和「嘴上」两层，嘴硬程度由性格决定 |
| 底色 | 六维性格 + 嘴硬，按星座从 50 基线加减，星座还附一条小脾气 |
| 关系 | 亲近、信任、依赖、安心、默契 |
| 主动额度 | 今天还能找你几条、最短间隔多久，按心情算（平常 3 条 / 心情好 5 条 / 低落 1 条 / 夜里不打扰） |
| 怕 | 只有看鬼片、打雷、一个人走夜路这类事才触发，按胆量定强度，几小时慢慢退 |
| 记忆 | 读一份 `memories.md`，画成会转的星图 |

## 界面

- 左：人物区 + 记忆星图（点开可放大）
- 中：现在（时间/年龄/生日/星座）、此刻（心里/嘴上/强度）、底色雷达、实时状态
- 右：身体·激素、关系、技能雷达、主动额度、戳一下试试
- 左上角 `?` 是整页说明，每张卡右上角的小问号是分区说明，鼠标移上去就能看
- 右下角齿轮：页面缩放、主题色（5 个预设 + 自定义色号，会同时改文字颜色）、角色资料与主动额度

## 装法

1. 装 Python 3.10+（只用标准库）
2. 解压后双击 `start.bat`，或者 `python server.py 8099`
3. 浏览器打开 <http://127.0.0.1:8099>
4. 第一次打开是空的：点右下角齿轮，填名字、生日、身高、主动额度，保存后自动刷新

## 配置

| 文件 | 作用 |
| --- | --- |
| `profile.json` | 角色设定（第一次保存后生成），可手改 |
| `profile.example.json` | 字段样例 |
| `memories.md` | 记忆，一行一条：`- [标题](文件) — 说明` |
| `model/model.json` | 可选，写 Live2D 模型的路径，例如 `{"path": "model/你的模型/你的模型.model3.json"}` |

**模型默认留空**：不放模型也能用，人物区会显示一行占位提示，其他面板照常。
要放模型就把自己的模型目录丢进 `model/`，再把路径写进 `model/model.json`；请使用自己有权的模型。

## 说明

- 所有数据都在本机，不联网、不上传
- 激素静息值、身体基线、关系五项、性格六维、技能六维都在 `profile.json` 里，可以手改
- 情绪引擎是纯函数式的：`engine.py` 里 `decay()` 推进时间，`feel()` 出「心里/嘴上」，`proactive()` 出主动额度
